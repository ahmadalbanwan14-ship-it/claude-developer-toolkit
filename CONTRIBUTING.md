# Contributing

Thanks for considering a contribution.

## Good contributions

- Fix a bug in an example
- Add a focused Claude API example
- Improve error handling, tests, or documentation
- Add a useful reusable helper without unnecessary dependencies

## Development setup

1. Fork the repository.
2. Create a branch from `main`.
3. Install with `pip install -e ".[dev]"`.
4. Run `pytest`.
5. Open a pull request describing what changed and why.

Never commit API keys, access tokens, private prompts, or private user data.

This is an independent community project and is not affiliated with or endorsed by Anthropic.
