# Roadmap

Claude Developer Toolkit is intentionally small and practical.

## Near term

- Improve examples for tool use and structured data
- Add async usage examples
- Add safer retry patterns for rate limits and transient failures
- Add streaming response examples
- Expand tests
- Improve documentation for common API mistakes

## Later

- Add reusable validation helpers
- Add example multi-tool workflows
- Add examples for prompt caching and long-context workflows when appropriate
- Add compatibility notes for SDK changes
- Add community-contributed examples

## Contribution philosophy

Changes should stay focused, readable, and useful to developers learning or building with the public Claude API. Avoid unnecessary framework dependencies or over-engineering.
